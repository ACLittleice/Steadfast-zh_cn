# Steadfast 0.9.0

Steadfast 0.9.0 带来了 Minecraft 26.3 支持，并在大多数配置下对水面、光照和天空进行了显著的视觉升级。

## Minecraft 26.3 支持

* 为 Wilderness Bound 方块添加了植被效果，包括杨树叶
* 在 26.3+ 上添加了对新版附魔光效渲染方法的支持

## 天空

* 太阳和月亮现在会在地平线以下逐渐淡出，使日落和日出更加可信、真实
* 星星现在会在日落/日出期间平滑淡入淡出
* 使 Semi-Natural 配置下的地平线稍微不那么明亮
* 修复了一个导致苍白花园天空变白的 Bug：该天空被错误地检测为星星
* 添加了一个用于降低卷云覆盖率的选项
* 卷云现在默认启用，并降低了覆盖率
* 修复了卷云与太阳之间异常的混合效果

## 水面

* 浅水现在非常清澈，不再过度偏蓝/青绿，整体颜色更加真实
	* 启用了对基于物理的水体吸收系数的支持
	* 将默认水体吸收系数替换为适用于更清澈水体的系数
	* 添加了水体散射，以模拟水中的泥土和其他杂质
	* 水体吸收现在部分基于光线在水体体积中穿行的距离，而不仅仅是该点水面以下的垂直深度
	* Fantasy 配置保留旧的水体吸收方法，因为它与该视觉风格更匹配。
* 添加了默认启用的粗糙折射，以改善清澈水体的可见性
* 水面现在使用物理准确的菲涅尔 F0 值
* 显著改善了地下水的着色
* 显著改善了流动水的着色
	* 此前，只有完全平坦的水面才具有反射/折射/吸收/波浪等效果，而流动水使用原版水纹理。
* 改进了在水下时对水面的着色
* 修复了在水下时地平线处难看的伪影

## 光照

* 添加了基于黑体色温的、物理正确的方块光颜色，并将默认颜色设为 3000K（黄色），而不是 2000K（橙色）
	* 这取代了之前的“橙色/不太橙色”方块光颜色切换选项。
	* 你可以选择 250K 到 12000K 之间的色温
	* 还添加了一种非物理的紫色光颜色，用于测试彩色光照算法
* 显著降低了应用于直射光的环境光遮蔽程度，以避免在直射阳光/月光下产生过度阴影。
* 夜间去饱和（浦肯野）效果现在会在暮光期间逐渐淡出。
	* 在我看来，这在禁用该选项和启用该选项之间取得了最佳平衡。此前，夜间去饱和会随着太阳落山而迅速淡出，这并不太真实。

## PBR 与资源包支持

* 在“检测常见自发光”选项后添加了可选的（默认禁用）哭泣的黑曜石内置 PBR
* 添加了对 PBR 资源包中环境光遮蔽和法线贴图的可选支持。
* 其他 PBR 资源包功能目前仍不支持，但已计划在未来加入。

## 光影设置

* 改进了光影选项界面，增加了额外选项，并给现有选项赋予了有意义的名称
* 在“开发/调试”下添加了一个用于修复 Create Aeronautics 光照的选项，由于性能影响，目前默认禁用。
* 修复了禁用水中焦散时可能出现的光影编译错误

## 性能

* 在相同设置下，Steadfast 0.9 的性能与 0.8 相同。
	* Steadfast 0.9 默认启用了更多功能，会带来轻微的性能影响。
* 改进了 Retro 配置中由重复雾效计算导致的性能问题
	* 这实际上是由一次有问题的优化造成的：该优化试图关闭单独的雾效渲染阶段，但并未正常工作。修复方法是始终使用单独的雾效渲染阶段。

## 内部实现

* 大幅重构了内部代码结构，为在现有 Iris 格式实现之外添加 Aperture 实现做准备
